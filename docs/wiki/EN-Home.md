# Overview & getting started

**Bastion** is a self-hosted reverse proxy and security control panel. A single Go binary contains the proxy, the API and the embedded web UI; PostgreSQL stores configuration and audit data.

## Features

- Reverse proxy with TLS termination (SNI, multiple certificates)
- Let's Encrypt (HTTP-01) with automatic renewal + manual certificate upload
- Multiple domains/aliases per site
- Templates with inheritance and per-site overrides
- **Path-based locations** with per-location upstream, auth, cache, rate limit and GeoIP overrides
- GeoIP filtering (DB-IP Lite) per location/site/template + tenant-wide rules
- CrowdSec bouncer, alerts and good-actor whitelist
- Global and per-site IP allow/deny lists (IPv4, IPv6, CIDR)
- Per-site Basic Auth with users and 3-failures/5-minute lockout
- Optional TOTP MFA for the GUI (authenticator apps)
- **Automatic 404 flood ban** (adds the IP to the blocklist with note `404`)
- Rate limiting (token bucket, per site + client IP)
- HTTP response cache honoring backend headers
- HTTP/2 and HTTP/3 (QUIC)
- Multi-tenancy + RBAC (superadmin, tenant_admin, editor, viewer)
- GUI in German and English (switch under Settings → Language & interface)
- Access logs (JSONL + combined log) and audit log
- Dashboard with system metrics, 24h traffic and certificate expiry
- Update check against GitHub releases

## Architecture

| Component | Technology |
|---|---|
| Backend / API | Go 1.26, Gin, GORM |
| Database | PostgreSQL |
| Frontend | React, Vite, Tailwind (embedded in the binary) |
| Proxy | `net/http` ReverseProxy, TLS SNI, quic-go (HTTP/3) |
| Certificates | certmagic (Let's Encrypt) + manual certificates |
| GeoIP | DB-IP Lite (MMDB) |
| Bouncer | CrowdSec LAPI |

## Paths and ports

| Path / port | Purpose |
|---|---|
| `/opt/bastion/bin/bastion` | Binary |
| `/opt/bastion/src` | Source code (when installed from the repo) |
| `/etc/bastion/config.yaml` | Configuration |
| `/etc/bastion/.secrets.env` | DB password and secrets (generated by the installer) |
| `/var/lib/bastion/certs` | Certificates (incl. ACME storage) |
| `/var/lib/bastion/geoip` | GeoIP database |
| `/var/lib/bastion/logs` | Access logs |
| `/var/lib/bastion/cache.json` | Persisted cache configuration |
| `/var/lib/bastion/version_cache.json` | Update-check cache (24 h) |
| `/var/lib/bastion/good-actors.yaml` | CrowdSec whitelist from the GUI |
| `:80` | HTTP → HTTPS redirect |
| `:443` | Proxy + GUI (HTTPS, HTTP/3) |
| `:8080` | API (HTTP, internal) |
| `127.0.0.1:8081` | CrowdSec LAPI |

## Request flow

1. TLS termination via SNI certificate.
2. **Admin host?** → GUI/API, security filters are skipped (lockout protection).
3. Global IP deny list → block.
4. CrowdSec ban → block.
5. Resolve site by `Host` (`domain` + `extra_domains`).
6. Site enabled? Otherwise `403`.
7. Site IP rules and optional Basic Auth.
8. GeoIP filter (location/site/template + rules).
9. Rate limit.
10. **Location match** by path prefix and apply overrides.
11. Response cache (HIT → served from RAM).
12. Otherwise reverse proxy to the upstream.

> **Admin hosts:** Any IP address used as a host is automatically an admin host. Additionally, `server.admin_hosts` applies; if empty, `localhost` is used; every IP address is also an admin host automatically. Set `server.admin_hosts` for your GUI domain. Admin hosts are exempt from IP lists, CrowdSec and GeoIP so you cannot lock yourself out.
