# Bastion Wiki

**Bastion** is a self-hosted reverse proxy and security control panel — TLS termination, Let's Encrypt, GeoIP filtering, CrowdSec, IP allow/deny lists, per-site Basic Auth, TOTP MFA, rate limiting and HTTP response caching in a single binary with an embedded web UI.
